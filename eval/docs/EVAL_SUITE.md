# Eval Suite — практическая валидация квантов MiniMax M2.5

Дата: 2026-03-21

Цель: оценить качество квантизации на реальных задачах с измеримыми баллами.
Каждый тест имеет максимальный балл и чёткие критерии оценки.

Общий максимум: **100 баллов** (10 тестов × 10 баллов).

---

## Как проводить

1. Запустить модель через llama-cli или llama-server с `-c 4096`
2. Подать каждый промпт **как есть** (без system prompt, если не указано)
3. Записать ответ модели полностью
4. Оценить по критериям
5. Сравнить баллы между квантами (Tapered-RAM v2, v3.1, UD-Q5, и т.д.)

## Тест 3: Поиск бага в коде (10 баллов)

### Промпт

```
Find all bugs in this code and explain each one:

def calculate_average(numbers):
    total = 0
    for i in range(len(numbers)):
        total += numbers[i]
    average = total / len(numbers)
    return round(average, 2)

def process_data(data):
    results = []
    for item in data:
        if item["type"] == "numeric":
            avg = calculate_average(item["values"])
            item["average"] = avg
            results.append(item)

    sorted_results = sorted(results, key=lambda x: x["average"], reverse=True)

    top_3 = sorted_results[:3]
    for i, result in enumerate(top_3):
        result["rank"] = i

    return results

data = [
    {"type": "numeric", "values": [1, 2, 3]},
    {"type": "text", "values": ["a", "b"]},
    {"type": "numeric", "values": []},
    {"type": "numeric", "values": [10, 20]},
]

print(process_data(data))
```

### Критерии оценки

| Баллы | Критерий |
|-------|---------|
| 3 | Найден критический баг: ZeroDivisionError на пустом списке |
| 2 | Найдено: мутация исходных объектов (item["average"], result["rank"]) |
| 2 | Найдено: rank начинается с 0, а не с 1 |
| 1 | Найдено: sorted_results не используется для возврата (возвращается results без сортировки) |
| 1 | Объяснения понятные и точные |
| 1 | Предложены исправления |

## Тест 11: Олимпиадная математика — AIME-уровень (10 баллов)

### Промпт

```
Find the number of ordered pairs (a, b) of positive integers such that:

a² + b² = a³

Express your answer as a single integer.
Show your complete reasoning.
```

### Решение для проверяющего

a² + b² = a³
b² = a³ - a² = a²(a - 1)
b = a√(a - 1)

Чтобы b было целым положительным числом, (a - 1) должно быть полным квадратом.
Пусть a - 1 = k², тогда a = k² + 1, b = (k² + 1) · k.

k ≥ 1 (иначе a = 1, b = 0 — не положительное).
Ограничений сверху на k нет → бесконечно много пар.

Но проверим: задача спрашивает ordered pairs of **positive integers**.
При любом k ≥ 1: a = k²+1, b = (k²+1)·k — оба положительные.
Ответ: **бесконечно много** (∞).

### Критерии оценки

| Баллы | Критерий |
|-------|---------|
| 3 | Корректное преобразование: b² = a²(a-1) |
| 3 | Понимание, что (a-1) должно быть полным квадратом |
| 2 | Правильный ответ: бесконечно много пар |
| 1 | Привёл примеры: (2,2), (5,10), (10,30), ... |
| 1 | Чёткое пошаговое изложение |

## Тест 12: Многошаговый reasoning с отслеживанием состояния (10 баллов)

### Промпт

```
Симулируй работу процессора по этим инструкциям. Регистры: A=0, B=0, C=0. Стек: пустой.

1. SET A 7
2. SET B 3
3. PUSH A
4. PUSH B
5. ADD          // снимает два верхних со стека, складывает, кладёт результат обратно
6. POP C        // снимает верхнее значение стека в C
7. SET A 2
8. MUL A C      // A = A * C, результат в A
9. PUSH A
10. PUSH C
11. SUB         // снимает два верхних: первый снятый - второй снятый, кладёт результат
12. POP B
13. CMP A B     // сравни A и B, установи FLAG: "GT" если A>B, "EQ" если A==B, "LT" если A<B
14. JMP_GT 16   // если FLAG == "GT", перейти к инструкции 16
15. SET A 0     // иначе выполни это
16. OUT A B C   // выведи значения A, B, C

Покажи состояние регистров и стека после КАЖДОЙ инструкции.
Какой будет финальный вывод OUT?
```

### Решение для проверяющего

```
1.  SET A 7      → A=7, B=0, C=0, Stack=[]
2.  SET B 3      → A=7, B=3, C=0, Stack=[]
3.  PUSH A       → A=7, B=3, C=0, Stack=[7]
4.  PUSH B       → A=7, B=3, C=0, Stack=[7, 3]
5.  ADD          → pop 3, pop 7, push 10 → Stack=[10]
6.  POP C        → C=10, Stack=[]
7.  SET A 2      → A=2, B=3, C=10, Stack=[]
8.  MUL A C      → A=2*10=20, Stack=[]
9.  PUSH A       → Stack=[20]
10. PUSH C       → Stack=[20, 10]
11. SUB          → pop 10, pop 20, 10-20=-10 → Stack=[-10]
    (первый снятый - второй снятый: 10 - 20 = -10)
12. POP B        → B=-10, Stack=[]
13. CMP A B      → A=20, B=-10, 20 > -10 → FLAG="GT"
14. JMP_GT 16    → FLAG=="GT", перейти к 16
15. (пропущена)
16. OUT A B C    → вывод: 20 -10 10
```

Финальный вывод: **A=20, B=-10, C=10**

### Критерии оценки

| Баллы | Критерий |
|-------|---------|
| 2 | Правильное значение C=10 после ADD+POP (шаги 5-6) |
| 2 | Правильное значение A=20 после MUL (шаг 8) |
| 2 | Правильное SUB: 10-20=-10 (порядок операндов при снятии со стека) |
| 2 | Правильный JMP_GT: пропуск инструкции 15 |
| 1 | Финальный вывод: 20 -10 10 |
| 1 | Показано состояние после каждой инструкции |

Примечание: SUB — ловушка. Многие модели путают порядок: "первый снятый минус второй снятый" (10-20=-10), а не наоборот.

## Тест 13: Adversarial reasoning — задача с подвохом (10 баллов)

### Промпт

```
Ответь на каждый вопрос. Будь внимателен — некоторые вопросы содержат ловушки.

1. У фермера было 17 овец. Все, кроме 9, убежали. Сколько осталось?

2. Самолёт летит из Москвы в Нью-Йорк и разбивается ровно на границе США и Канады. Где хоронят выживших?

3. Что тяжелее: килограмм железа или килограмм перьев?

4. В семье 5 сыновей. У каждого сына есть сестра. Сколько детей в семье?

5. Перед тобой три выключателя. За стеной — комната с одной лампочкой (обычная лампа накаливания). Ты можешь зайти в комнату только один раз. Как определить, какой выключатель управляет лампочкой?

6. У тебя есть 8 одинаковых на вид шаров. Один из них тяжелее остальных. У тебя есть весы-балансир. Какое минимальное число взвешиваний гарантированно определит тяжёлый шар?

7. Если 5 машин за 5 минут делают 5 деталей, за сколько минут 100 машин сделают 100 деталей?
```

### Правильные ответы

1. **9** (все кроме 9 убежали)
2. **Выживших не хоронят** (они живы)
3. **Одинаково** (оба по килограмму)
4. **6** (5 сыновей + 1 общая сестра)
5. **Включить 1-й на 5 минут, выключить, включить 2-й, зайти**. Горит = 2-й. Тёплая не горит = 1-й. Холодная не горит = 3-й.
6. **2 взвешивания** (3+3+2, потом сужаем)
7. **5 минут** (каждая машина делает 1 деталь за 5 минут)

### Критерии оценки

| Баллы | Критерий |
|-------|---------|
| 1 | Вопрос 1: ответ 9, не 8 |
| 1 | Вопрос 2: "выживших не хоронят" |
| 1 | Вопрос 3: одинаково |
| 2 | Вопрос 4: 6 детей (не 10) — частая ошибка LLM |
| 2 | Вопрос 5: метод с нагревом лампы (не простой перебор) |
| 2 | Вопрос 6: ответ 2 с объяснением алгоритма |
| 1 | Вопрос 7: 5 минут (не 100) |

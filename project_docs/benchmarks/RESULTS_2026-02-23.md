## Key Findings

### 1. muge+rtr crash fix
- **Verified on 3 different MoE models** with 3 different quant types
- Qwen3-30B-A3B Q4_K_M: previously crashed, now works
- Qwen3-42B-A3B MXFP4: previously crashed, now works
- qwen3next architecture: muge doesn't fuse experts (different internal structure), but fix doesn't break anything

### 2. Expert prefetch
- **No measurable improvement for in-RAM models** — all data in OS page cache
- This is expected: prefetch benefits come from reducing latency for swap-bound models
- **Expected real benefit for MiniMax-M2.5 (151 GB on 96 GB RAM)**: experts paged from swap, prefetch reduces page fault stall

### 3. UD-Q compatibility
- **UD-Q types are standard GGML types internally** (UD-Q8_K_XL = Q8_0, UD-Q6_K_XL = Q6_K, etc.)
- All UD-Q models work correctly with rtr and our optimizations
- IQK MoE kernels support **38+ GGML types** including all K-quants, IQ types, MXFP4, and repacked variants

### 4. No regressions
- Dense models: Llama-3.1-8B unchanged (8.28 vs 8.2 baseline)
- MoE models: All within noise of baseline
- New models tested: All working correctly

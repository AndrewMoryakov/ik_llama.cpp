## Known Issues

### -muge crash on gpt-oss-20b MXFP4
- `-muge` flag causes exit 127 (no output) on gpt-oss-20b MXFP4
- Tested on current commit AND old bd387a279 — same crash on both
- **Pre-existing issue, NOT a regression from upstream merge**
- Root cause: likely Large Pages + muge contiguous allocation conflict
- **Use muge=0 always for gpt-oss-20b. Do not add -muge to any gpt-oss-20b preset.**

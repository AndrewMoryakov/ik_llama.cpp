Optimization

ik_llama-specific runtime switches, cache formats, and MoE controls.

Optimization ik_llama fork
-fa Flash Attention
ON
Optimized attention kernel. Always recommended ON
-rtr Runtime Repack
Three modes: off, on, auto. AUTO is throughput-first for Qwen3MoE/gpt-oss, while MiniMax still uses OFF as the safer baseline.
-muge Merge Up+Gate
OFF
Merge ffn_up + ffn_gate into one tensor. MoE only. No stable win is confirmed; swap-bound regression risk is high.
-ctk KV Cache K
Quantization for K-cache. q8_0 is the current safe baseline and saves a lot of memory
-ctv KV Cache V
Quantization for V-cache. Can be more aggressive than K (q4_0 for max context)
-mla MLA Mode
Multi-head Latent Attention mode. 3 = auto-select best for model
-gr Graph Reuse
ON
Reuse compute graph between tokens. Default ON, rarely needs changing
-khad K-Cache Hadamard
OFF
Hadamard transform for K-cache. Only useful with quantized cache (q8_0, q4_0, etc.)
-no-fmoe Fused MoE
ON
Fused up*gate op for MoE models. Default ON
-no-fug Fused Up*Gate
ON
Fused up*unary(gate) op. Default ON
Experimental knobs
These controls stay outside the validated baseline. They are meant for targeted A/B checks and runtime research, not as default recommendations.
Метки рядом с параметром показывают три разные вещи: для какого класса моделей он подходит по механике, где текущий runtime реально его поддерживает и где уже есть подтвержденный сигнал от бенчмарков.
Experimental preset
Model-aware bundles of experimental knobs. They are shortcuts for targeted A/B checks, not safe defaults.
link Link preset to validated settings
ON
If ON, applying an experimental preset may also adjust validated knobs such as Flash Attention or RTR when that bundle depends on them. If OFF, only experimental controls change.
-ser Smart Expert Reduction
Drop low-weight experts below threshold, keep at least min. Reduces swap I/O for MoE. May affect quality
--experimental Hot Expert Budget
Experimental env knob for huge MoE. 0 = leave runtime default. On current MiniMax, the first longer controlled run did not justify promoting a larger default, so start with 0.
--experimental Hot Expert Budget Mult
A multiplier over the runtime hot-expert baseline. 0 = leave the runtime default. Use it only for controlled MoE locality A/B when a fixed budget is too coarse.
--experimental Hot Expert Selection
How the runtime chooses hot experts after the first prompt. For MiniMax locality research, tail-window uses only the last prompt tokens instead of the full prompt.
--experimental Tail Window
When Hot Expert Selection = tail-window, use the last N prompt tokens to predict the first decode steps. Smaller windows are more local; larger windows behave more like full-prompt.
--experimental Tail Blend
Soft blending factor (0–0.99) for early expert hits at the tail-window boundary. 0 = hard reset (default). Values like 0.3 scale early hits by 30% before the tail window starts accumulating, preserving partial early signal.
-mqkv Merge QKV
OFF
Merge Q, K, V into one contiguous tensor for attention
--experimental Prompt Packed QKV
OFF
Experimental prompt-only attention path that packs split Q/K/V projections into a more locality-friendly runtime layout. It can improve prompt-side work, but may cost extra RAM or load time.
--experimental Prompt Packed preset
Predefined layer ranges for Prompt Packed QKV. On current research data, Qwen tends to prefer front-half, while gpt-oss tends to prefer back-half.
--experimental Prompt Packed range
Optional explicit layer range such as 0:24 or 12:24. If set, it overrides the preset and is meant for advanced A/B checks only.
ui Live Observability
ON
Dashboard-only traces for live phase flow and MoE experts activity. Useful for learning and debugging; disable for the cleanest benchmark runs.
How these change execution
These knobs do not change model weights. They change runtime behavior: which experts are kept hot, how much of the prompt is trusted as a predictor of early decode, and whether the router is allowed to drop very weak experts. Start with one knob at a time and compare against the validated baseline.

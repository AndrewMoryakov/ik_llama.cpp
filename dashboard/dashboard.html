Workload
What matters most to you: real prompt+generation flow, decode-only throughput, or prompt processing. Recommendations differ.
-t Threads
Inference threads. Zen4 dual-CCD: 16 is a good baseline; for in-RAM models also A/B test 24/32
-tb Threads (batch)
Threads for prompt processing. -1 = same as -t
-c Context size
Context window in tokens. 0 = auto from model metadata
-b Batch size
Logical batch size for prompt processing (min 32)
-ub Micro-batch size
Physical batch size (min 32, must be <= batch size)
Optimization ik_llama fork
-fa Flash Attention
ON
Optimized attention kernel. Always recommended ON
-rtr Runtime Repack
Three modes: off, on, auto. AUTO is throughput-first for Qwen3MoE/gpt-oss, while MiniMax still uses OFF as the safer baseline.
-muge Merge Up+Gate
OFF
Merge ffn_up + ffn_gate into one tensor. MoE only. No stable win is confirmed; swap-bound regression risk is high.
-ctk KV Cache K
Quantization for K-cache. q8_0 is the current safe baseline and saves a lot of memory
-ctv KV Cache V
Quantization for V-cache. Can be more aggressive than K (q4_0 for max context)
-mla MLA Mode
Multi-head Latent Attention mode. 3 = auto-select best for model
-ser Smart Expert Reduction
Drop low-weight experts below threshold, keep at least min. Reduces swap I/O for MoE. May affect quality
env Hot Expert Budget
Experimental env knob for huge MoE. 0 = leave runtime default. On current MiniMax, the first longer controlled run did not justify promoting a larger default, so start with 0.
ui Live Observability
ON
Dashboard-only traces for live phase flow and MoE experts activity. Useful for learning and debugging; disable for the cleanest benchmark runs.
-gr Graph Reuse
ON
Reuse compute graph between tokens. Default ON, rarely needs changing
-mqkv Merge QKV
OFF
Merge Q, K, V into one contiguous tensor for attention
-khad K-Cache Hadamard
OFF
Hadamard transform for K-cache. Only useful with quantized cache (q8_0, q4_0, etc.)
-no-fmoe Fused MoE
ON
Fused up*gate op for MoE models. Default ON
-no-fug Fused Up*Gate
ON
Fused up*unary(gate) op. Default ON

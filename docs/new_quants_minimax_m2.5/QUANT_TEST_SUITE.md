# Канонический набор для сравнения квантов MiniMax M2.5

Назначение: одинаковыми задачами сравнивать кванты (Taper28, TaperedRAM, будущий
BF16) и находить границу деградации. Не тест «умности модели» — тест того, что
теряет квант.

## Калибровка (важно)

MiniMax M2.5 даже в BF16 — средний уровень. Поэтому задачи подобраны в её
потолок: не фронтир-сложность (иначе провалит и BF16, сигнала нет) и не тривиал
(иначе решит и iq1_s). **Перед использованием прогнать набор на TaperedRAM
(91 ГиБ) как контроль.** Любую задачу, которую TaperedRAM не решает на полный
балл, — упростить или выбросить: значит она за потолком модели, а не различает
кванты.

## Протокол

- Temperature = 0, один и тот же промпт, без system-подсказок, ~512 токенов.
- Один прогон на задачу на каждом кванте. Одинаково для всех квантов.
- Оценка по задаче: 2 (полностью верно), 1 (частично), 0 (неверно). Итог /10.

## Задачи

### T1 — Многошаговый счёт (точность на длине). Ось: арифметика.
```
Магазин: тетради по 45 руб., ручки по 30 руб., папки по 120 руб. Покупатель
берёт 8 тетрадей, 5 ручек и 3 папки. На всю покупку действует скидка 10%, а
после скидки добавляется доставка 150 руб. Сколько покупатель заплатит итого?
Реши по шагам, последняя строка строго: ОТВЕТ: <число> руб.
```
Верно: 8·45=360, 5·30=150, 3·120=360 → 870; −10% = 783; +150 = **933 руб.**
Оценка: 2 — финал 933 и шаги верны; 1 — верный метод, арифметическая ошибка;
0 — неверный подход/формат.

### T2 — Следование формату (точность инструкции). Ось: контроль вывода.
```
Назови ровно 5 цветов. Требования: каждый одним словом, все строчными буквами,
по алфавиту, разделены строкой ' | ' (пробел, вертикальная черта, пробел). В
ответе не должно быть ничего, кроме этих пяти слов с разделителями.
```
Верно: ровно 5 слов, строчные, по алфавиту, разделитель ` | `, без лишнего
текста (конкретные слова любые — проверяем ФОРМАТ и порядок, не список).
Оценка: 2 — все требования; 1 — нарушено одно (напр. не по алфавиту или 6 слов);
0 — нарушено два и более / есть посторонний текст.

### T3 — Код с краевым случаем. Ось: программирование (самая чувствительная).
```
Напиши функцию на Python `two_sum(nums, target)`, которая возвращает индексы
двух чисел из списка nums, дающих в сумме target, в виде списка [i, j] с i<j.
Гарантируется ровно одно решение. Пример: two_sum([2,7,11,15], 9) даёт [0,1].
Верни только код функции.
```
Верно: рабочая two_sum, на примере возвращает [0,1], i<j. Проверять запуском.
Оценка: 2 — код верный и проходит пример; 1 — почти верный (мелкий баг/индексы);
0 — не работает / не код.

### T4 — Точное преобразование данных (без знаний). Ось: верность извлечения.
```
Дан текст:
Анна, 34
Борис, 28
Вера, 41
Глеб, 22
Выведи имена и возраст в формате имя:возраст, по одному на строке,
отсортировав по возрасту по возрастанию. В ответе только эти строки.
```
Верно (ровно, по порядку):
```
Глеб:22
Борис:28
Анна:34
Вера:41
```
Оценка: 2 — все 4 строки, верный порядок и формат; 1 — одна ошибка (порядок или
формат); 0 — две и более.

### T5 — Микрофакты (точность знаний). Ось: не размывает ли редкое.
```
Ответь кратко, по одному пункту на строку, только сам ответ без пояснений:
(1) химический символ золота;
(2) сколько сторон у шестиугольника;
(3) столица Японии.
```
Верно: **Au** / **6** / **Токио**. (Всё тривиально — провал = деградация кванта,
а не незнание.)
Оценка: 2 — все три; 1 — две из трёх; 0 — одна или ноль.
